RDS Address Book Sample Overview

Address Book Sample
This sample requires the Northwind database which comes preinstalled as one of the sample databases in SQL Server 7 and greater. This database is also the same as the Microsoft Access sample database NWind.mdb.
The connection strings for either SQL Server or Access databases are in the sample but with the Access connect string commented out.

Setup

  1. Verify the connection string is valid for your environment.
  2. Copy this .asp to a virtual root on your web server.

Running the Sample

Follow the instructions below to run this sample.
Open the AddrBook.ASP page in your web browser.

System Requirements

This application requires the following system components to run.
  • Microsoft Windows NT 4.0 or Windows 2000
  • Microsoft Internet Information Services version 4.0 or 5.0
  • SQL Server 7.0 or newer
