Microsoft .NET Framework SDK

Welcome to the Microsoft .NET Framework Software Development Kit 2.0. The .NET Framework SDK is the essential reference for developers who use the .NET Framework technologies.

 Getting Started

For those who are new to the .NET Framework technologies, the Overview of the .NET Framework section of the .NET Framework SDK documentation is designed to point you in the right direction.

It includes overview and conceptual information about .NET Framework fundamentals such as the Common Language Runtime, the Common Type System, Cross Language Interoperability, Metadata, and Application Domains.

For a quick overview of what's new in version 2.0 of the .NET Framework, see What's New in the .NET Framework 2.0, which describes new features such as 64-bit platform support, Access Control List (ACL) support, new ADO.NET and ASP.NET features, COM Interoperability, Disjunctive Demands, Generics, and more.

  
 QuickStarts, Tutorials and Samples

The .NET Framework SDK QuickStarts, tutorials, and samples are designed to quickly acquaint you with the programming model, architecture, and components that comprise the .NET Framework.

The .NET Framework documentation includes Application samples that represent complete applications written for the .NET Framework and the .NET Compact Framework, and Technology samples that demonstrate .NET Framework features.

The LateBreaking samples folder contains newly added samples that supplement the samples included in the documentation.

You can download the latest samples, including LateBreaking samples, from the online samples download page.
  Documentation   Tools and Debuggers

The .NET Framework SDK documentation provides a wide range of overviews, programming tasks, and class library reference information that is designed to help you build efficient, powerful, and scalable applications based on the .NET Framework technologies.

For a list of the modifications to the class library for the .NET Framework, see the Class Library Changes and Additions.


The .NET Framework SDK tools and debuggers enable you to create, deploy, and manage applications and components that target the .NET Framework. 

 Feedback 

We are working hard to make sure that the .NET Framework technologies and the SDK enable you to build great applications.  Your feedback is extremely valuable to us. Please send us your comments and suggestions.   You can also visit the .NET Framework SDK newsgroups.

For known issues and late-breaking information see the Release Notes.

 

Note: To run applications that use Visual J#, the Visual J# Redistributable Package 2.0 must be installed in addition to the .NET Framework. See the redistributable readme file for more information.

Note: To build and run .NET Compact Framework samples, the .NET Compact Framework Redistributable Package 2.0 must be installed in addition to the .NET Framework. See the redistributable readme file for more information.
