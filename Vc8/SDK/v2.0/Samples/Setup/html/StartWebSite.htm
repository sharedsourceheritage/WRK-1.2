Microsoft .NET Framework SDK QuickStart Web Site is not started.

To start the web site:

  • Open the IIS manager buy entering the command inetmgr in the run window.
  • Browse to Default Web Site node found at IIS\<computerName>\WebSites\Default Web Site
  • Right Click the node and select start.

After the web site is started, launch the quickstarts by opening the Quickstart Tutorials from the Start Menu.
