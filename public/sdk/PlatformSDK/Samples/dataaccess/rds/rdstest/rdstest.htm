RDS RDSTest Sample

Sample Overview

RDSTest is a basic sample which demonstrates creating a recordset in a 3-tier environment and navigating over that recordset.

Setup

This sample requires the Northwind database, as does the Address book sample. This sample also has connection strings for both SQL Server and Access databases. To use the Access connection string, change the SQLBACKEND contstant as follows:
From: Const SQLBACKEND = True
To: Const SQLBACKEND = False

  1. Verify the connection string is valid for your environment.
  2. Copy this .asp to a virtual root on your web server.

Running the Sample

Follow the instructions below to run this sample.
Open the RDSTest.ASP page in your web browser.

System Requirements

This application requires the following system components to run.
  • Microsoft Windows NT 4.0 or Windows 2000
  • Microsoft Internet Information Services version 4.0 or 5.0
  • SQL Server 7.0 or newer
